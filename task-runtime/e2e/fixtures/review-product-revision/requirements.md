# Record codec product requirement (live canary)

Build a dependency-free ESM library in `app/records.mjs`. The public exports must be `encodeRecord({id,label})`, `decodeRecord(line)` and `groupByLabel(records)`. `id` and `label` are strings; the empty string is valid. The wire format is `id|label` with `\\` encoded as `\\\\` and `|` encoded as `\\|` within each field. A backslash escapes exactly the following backslash or pipe; literal Unicode characters remain unchanged. Encoding then decoding must recover the exact original strings, including empty, `|`, `\\`, consecutive backslashes and combined escape cases. `groupByLabel` returns a Map from exact, case-sensitive labels to arrays of the original record objects, preserving record order without mutating its input. No network, filesystem access, extra dependencies, installation, commit, push or target modification during delivery.

The existing `app/records.mjs` is an incomplete starting point, not a solution. The designated smoke test covers ordinary round trips and grouping; it does **not** claim to cover escaping or all edge cases. A final independent reviewer must evaluate the complete requirement. If the first candidate has a genuine product blocker, a new regression may be added under the original sealed scope and the review-origin revision protocol. If the first candidate is correct, do not manufacture a BLOCKED finding or retry to force coverage.
